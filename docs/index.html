Phase 1 · Architecture design

Shoplane: an AI-assisted store on AWS and Google Cloud

Shoplane is a small e-commerce site built one production upgrade at a time. The store runs on AWS: a highly available 3-tier core, serverless checkout and a security layer. The AI layer runs on Google Cloud: semantic search, a Gemini shopping assistant and recommendations, reached over HTTPS with keyless Workload Identity Federation. Hybrid trade-offs

What two clouds cost you, and what they buy

Splitting the system across AWS and Google Cloud adds a network hop, egress charges, a second bill and a second identity model. The design keeps each one small and visible.

Cost notes

Where the money goes

Most of this design is pay-per-request and costs pennies at demo traffic. A handful of resources bill by the hour whether or not anyone visits. Those are the ones to destroy after every session.

Key decisions

Choices and the trade-offs behind them

Terraform

Module coverage in tfmodules

Every resource is created through modules in roshhegde/tfmodules, from one Terraform configuration that uses both the aws and google providers. The repository already covers the AWS network, containers, serverless and identity pieces. It has no Google Cloud modules yet. Missing modules are added in the phase that first needs them, one module per cloud service.
